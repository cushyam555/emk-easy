# EMK Easy

โปรแกรมแยกเพลง EMK เป็น NCN ใช้งานผ่าน Chrome หรือ Microsoft Edge รองรับ EMK V2

## ดาวน์โหลดและเริ่มใช้งาน

1. เปิดหน้า [Releases](https://github.com/cushyam555/emk-easy/releases/latest)
2. ดาวน์โหลด **EMK-Easy-v1.0.0.zip** แล้วแตกไฟล์ หรือดาวน์โหลด **EMK-Easy.html** โดยตรง
3. ดับเบิลคลิก `EMK-Easy.html` เพื่อเปิดใน Chrome หรือ Edge รุ่นปัจจุบัน
4. เลือกหรือลากไฟล์ `.emk` เข้าหน้าต่าง
5. เลือก **NCN ครบชุด** หรือ **MIDI เท่านั้น** แล้วกด **แปลงไฟล์**
6. กด **ดาวน์โหลด ZIP** และแตกไฟล์ผลลัพธ์

ใช้ได้แบบออฟไลน์ ไม่ต้องติดตั้งโปรแกรมหรือเปิดเซิร์ฟเวอร์

## ความสามารถ

- แปลงหลายเพลงพร้อมกัน สูงสุด 100 เพลงต่อชุด
- แยก `.mid`, `.lyr`, `.cur` หรือเลือกเฉพาะ MIDI
- แสดงผลสำเร็จและข้อผิดพลาดแยกรายไฟล์
- เก็บชื่อเพลงจากชื่อไฟล์ต้นฉบับ และเติมเลขท้ายเมื่อชื่อซ้ำ
- ตรวจส่วนหัวและขอบเขตแทร็ก MIDI ก่อนบันทึก
- ดาวน์โหลดผลลัพธ์เป็น ZIP พร้อมรายงานผล
- ประมวลผลในเครื่อง ไฟล์เพลงไม่ถูกอัปโหลด และต้นฉบับไม่ถูกแก้ไข

## โครงสร้างผลลัพธ์

```text
NCN/
  Song/ชื่อไฟล์.mid
  Lyrics/ชื่อไฟล์.lyr
  Cursor/ชื่อไฟล์.cur
รายงานผล.json
```

ขนาดไฟล์สูงสุด 128 MB ต่อไฟล์ และจำกัดผลลัพธ์รวมประมาณ 128 MB ต่อชุด หากมีหลายเพลงขนาดใหญ่ให้แบ่งแปลงเป็นหลายชุด

## สำหรับผู้พัฒนา

ใช้ Node.js 22 ขึ้นไป ไม่มี dependency เพิ่มเติม

```sh
npm run build
npm test
```

- `src/core.js` — อ่าน EMK ตรวจ MIDI และสร้าง ZIP
- `src/page.html` — หน้าจอและขั้นตอนการใช้งาน
- `build.mjs` — รวมเป็น HTML ไฟล์เดียว
- `tests/` — ทดสอบการแปลงและขั้นตอนใช้งานด้วยข้อมูลจำลอง
- `downloads/EMK-Easy.html` — ไฟล์พร้อมเปิดใช้งาน

Repository นี้ประกอบด้วยโปรแกรมและข้อมูลทดสอบที่สร้างขึ้นเอง ไม่รวมเพลงหรือโปรแกรมต้นฉบับของผู้ผลิตคาราโอเกะ
