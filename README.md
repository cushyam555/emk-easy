# EMK Easy

โปรแกรม Windows สำหรับแยกเพลง EMK V2 เป็น MIDI หรือ NCN ครบชุด

## ดาวน์โหลดโปรแกรม Windows

เปิดหน้า [Releases](https://github.com/cushyam555/emk-easy/releases/latest) แล้วดาวน์โหลด **EMK-Easy.exe** หรือ **EMK-Easy-Windows-x64-v1.0.1.zip**

1. หากดาวน์โหลด ZIP ให้แตกไฟล์ก่อน
2. ดับเบิลคลิก `EMK-Easy.exe`
3. เลือกหรือลากไฟล์ `.emk` ลงหน้าต่าง
4. เลือก **NCN ครบชุด** หรือ **MIDI เท่านั้น** แล้วกด **แปลงไฟล์**
5. กด **บันทึก ZIP** เลือกตำแหน่ง แล้วบันทึกผลลัพธ์

โปรแกรมเป็น Windows 64 บิต มีหน้าต่างใช้งานในตัว ไม่ต้องเปิด HTML หรือเปิดเซิร์ฟเวอร์ ใช้งานแบบออฟไลน์ได้ ต้องมี Microsoft Edge WebView2 Runtime ซึ่งมักติดตั้งอยู่แล้วบน Windows 10/11 หากยังไม่มีให้ติดตั้งจาก [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/)

ตัวแปลงและระบบบันทึกไฟล์ผ่านการทดสอบอัตโนมัติแล้ว ตัว EXE สร้างโดย cross-compile บน Linux และตรวจโครงสร้าง Windows PE แล้ว แต่ยังไม่ได้ทดสอบเปิดหน้าต่างจริงบน Windows

## ความสามารถ

- แปลงหลายเพลงพร้อมกัน สูงสุด 100 เพลงต่อชุด
- แยก `.mid`, `.lyr`, `.cur` หรือเลือกเฉพาะ MIDI
- แสดงผลสำเร็จและข้อผิดพลาดแยกรายไฟล์
- จัดการชื่อซ้ำและชื่อภาษาไทย
- ตรวจส่วนหัวและขอบเขตแทร็ก MIDI ก่อนบันทึก
- บันทึก ZIP พร้อมรายงานผลผ่านหน้าต่างเลือกไฟล์ของ Windows
- ประมวลผลในเครื่อง ไฟล์เพลงไม่ถูกอัปโหลด และต้นฉบับไม่ถูกแก้ไข

```text
NCN/
  Song/ชื่อไฟล์.mid
  Lyrics/ชื่อไฟล์.lyr
  Cursor/ชื่อไฟล์.cur
รายงานผล.json
```

ไฟล์ละไม่เกิน 128 MB และผลลัพธ์รวมประมาณ 128 MB ต่อชุด หากเพลงมีขนาดใหญ่ให้แบ่งแปลงเป็นหลายชุด

## HTML สำหรับเปิดในเบราว์เซอร์

ยังมี `downloads/EMK-Easy.html` สำหรับใช้แบบออฟไลน์ผ่าน Chrome หรือ Edge ได้เช่นเดิม

## สำหรับผู้พัฒนา

หน้าโปรแกรมใช้ Node.js 22 ขึ้นไป ไม่มี dependency เพิ่มเติม

```sh
npm run build
npm test
```

สร้าง Windows EXE ด้วย Node.js 22 และ Go 1.22 ขึ้นไป:

```powershell
powershell -File windows/build.ps1
```

ผลลัพธ์อยู่ที่ `downloads/EMK-Easy.exe`

- `src/core.js` — อ่าน EMK ตรวจ MIDI และสร้าง ZIP
- `src/page.html` — หน้าจอและขั้นตอนการใช้งาน
- `windows/main_windows.go` — หน้าต่าง WebView2 และหน้าต่างบันทึก ZIP
- `windows/savedata.go` — ตรวจข้อมูลและเขียนไฟล์ผลลัพธ์
- `windows/prepare.mjs` — เตรียมหน้าจอสำหรับฝังใน EXE
- `windows/THIRD-PARTY-NOTICES.txt` — ใบอนุญาตของส่วนประกอบภายนอกที่ใช้ใน EXE
- `tests/` — ทดสอบตัวแปลงและขั้นตอนใช้งาน

Repository นี้ประกอบด้วยโปรแกรมและข้อมูลทดสอบที่สร้างขึ้นเอง ไม่รวมเพลงหรือโปรแกรมต้นฉบับของผู้ผลิตคาราโอเกะ
